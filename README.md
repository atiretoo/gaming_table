# Modular Kitchen & Dining Gaming Table

A compact, modular dining table designed for small kitchens and apartments that transforms into a recessed tabletop gaming table.

## Key Features

- **Dual-Function Design**: Functions as a dining / kitchen work surface with a flat tabletop, which lifts off to reveal a recessed gaming vault for board games, cards, and puzzles.
- **Spill Protection**: The tabletop leaves overlap the perimeter stretchers with a protective overhang so spills cannot seep into the game vault.
- **Two-Piece Tabletop**: Removable in two lightweight halves, located and held securely horizontally by dowel pins dropping into mating holes in the side stretchers.
- **Modular & Disassembleable**: Designed with knock-down joinery (threaded inserts and bolt-fastened corner blocks) for rapid disassembly, moving, and reassembly.
- **Baltic Birch Plywood Construction**: Optimized for standard 18mm (3/4") and 12mm (1/2") Baltic birch plywood, with hardwood edge banding and fine veneer.
- **Compact Ergonomics**:
  - Width: Sized for one comfortable dining place setting at the narrow end (e.g. 28" – 30").
  - Length: Twice the width (up to 60" maximum, e.g. 56" – 60").
  - Height: Standard 29.5" – 30" dining height with comfortable 24.5"+ knee clearance.
